# Contributing

Contributions are welcome for non-commercial use under the repository license.

1. Open an issue for substantial changes.
2. Keep changes focused and add regression tests.
3. Run the Swift package tests and root `swift build`.
4. Run the unsigned iOS simulator build when changing the app.
5. Submit a pull request describing behavior changes and verification.

Do not commit credentials, generated build output, private examples, or assets without documented redistribution rights.
